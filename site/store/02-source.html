Layer 1 · JSON pruning

Mid-rolls are removed at the source.

Ad metadata is stripped out of YouTube’s /youtubei/v1/player response before the player reads its configuration — without touching the fields that carry playback.

POST /youtubei/v1/player intercepted in the page’s own JavaScript realm, at document_start
−"adPlacements": [ … ]pruned
−"playerAds": [ … ]pruned
−"adSlots": [ … ]pruned
−"adBreakHeartbeatParams": "…"pruned
✓"streamingData": { … }never touched
✓"videoDetails": { … }never touched
✓"captions", "storyboards", "playabilityStatus"never touched
No adPlacements means no ad break to schedule — there is no Skip button, because there is nothing to skip.
