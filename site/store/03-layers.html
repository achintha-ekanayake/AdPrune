Defense in depth

Four independent layers.

If one layer misses a newly renamed field, the next still gets you through. Every hook installs inside its own try/catch, so the worst outcome is an ad getting past — not video breaking.

1 JSON pruning MAIN world Strips ad metadata from InnerTube responses. Kills mid-rolls.
2 Cosmetic + watchdog ISOLATED world Hides page ad units; skips any ad that slipped past Layer 1.
3 Background Service worker Settings, stats, badge and ruleset toggling.
4 Network rules declarativeNetRequest Ad-network hosts and ad-tracking pings.

Chrome’s MV3 dropped blocking webRequest, so Layer 4 is weaker there than on Firefox. Layer 1 carries the load on both — which is why the JSON layer, not the network layer, is the primary defense.
